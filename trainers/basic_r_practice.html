Basic R practice

How to work

This practice contains 11 core tasks followed by two optional tasks. Each task is independent. Write R code that saves the requested answer as result.

On Stepik, the input variables are prepared automatically and your saved result is checked automatically. Here you need to check your answers by yourself.

Quarto

This is a Quarto document, saved with the .qmd extension. It combines Markdown text with executable R code in chunks. Quarto uses knitr to run R code.

getwd()
[1] "/Users/vladstanin/Преподавание/ITMO_Biostat_R/code"
x <- 2
f <- 2
x + f
[1] 4

To run the whole code in chunk - press green “play” button
To run only one line - with the cursor on the line, press Ctrl + Enter / Cmd + Enter

Our first command, getwd(), returns the current working directory. We can create multiple chunks to run code separately.

Ctrl+Alt+I / Cmd+Options+I - to create new chunk.
Or on top of the screen: Insert > Executable cell > R

{r} means that the code should be interpreted as R.

We can configure chunks using Quarto cell options. Add these comments at the start of a chunk:

#| warning: false
#| message: false
#| echo: false
#| eval: false
  • warning: false hides warnings in the rendered document.
  • message: false hides messages.
  • echo: false hides the code while keeping its results.
  • eval: false prevents the code from running during rendering.

Use only the options you need. To display code without running it, use eval: false and leave echo enabled.

To set document-wide options, add an execute block to the YAML header at the top of the .qmd file:

execute:
  echo: true
  warning: false
  message: false

For R-specific settings, you can also use knitr::opts_chunk$set() in a setup chunk:

knitr::opts_chunk$set(echo = TRUE, out.width = "100%")

Implicit type conversion in arithmetic

R can convert types automatically during arithmetic, whether you use values directly or store them in variables. Logical values become numbers: TRUE becomes 1, and FALSE becomes 0.

flag <- TRUE
flag + 2       # 3: TRUE becomes 1
[1] 3
10 - flag      # 9: TRUE becomes 1
[1] 9
FALSE * 10     # 0: FALSE becomes 0
[1] 0
TRUE + TRUE    # 2: both values become 1
[1] 2
TRUE / 2       # 0.5
[1] 0.5
2 ^ FALSE      # 1: FALSE becomes 0
[1] 1

Text is not automatically converted to a number in arithmetic, even if it looks numeric:

text_number <- "3"
text_number + 2  # Error: text + number
"3" * 2         # Error: text * number
10 - "3"        # Error: number - text
"3" + TRUE      # Error: text + logical value
"3" + "2"       # Error: + does not join text

The error examples are commented out so the document can render. Uncomment one line at a time to try them.

Convert numeric text explicitly before calculating:

as.numeric(text_number) + 2 # 5
[1] 5
as.numeric("3") * 2        # 6
[1] 6
